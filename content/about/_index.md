## 关于这个博客

这里主要写技术文章，也会记录一些项目进展、读过的书、看过的电影和走过的路。

写博客对我来说更像是一份公开的笔记：先把想法整理清楚，再决定它是否值得留下。所以这里的文章大多偏长，也会有反复修改。

评论功能用的是 [Giscus](https://giscus.app)，评论直接存在 GitHub Discussions 里，不需要注册任何账号——登录 GitHub 就能留言。

## 关于我

平时的兴趣集中在开发工具、系统效率和自动化上。工作之外的时间，多数花在折腾上面那些工具上，以及把过程写下来。

如果你在这里看到某篇文章对你有用，欢迎留言交流。
