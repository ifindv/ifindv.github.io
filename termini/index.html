面向 SSH 与本地终端的桌面客户端A desktop client for SSH and local shells

所有会话都活在同一个窗口的标签页里——连接、传输、转发，都不离开这一块屏幕。Every session you open lives in a tab of one window — connections, transfers and tunnels without leaving the screen.

基础功能免费使用。Pro 是可选的微软商店订阅，试用与续订都由商店处理。The base app is free to use. Pro is an optional Microsoft Store subscription; the trial and renewal are handled by the Store.

多标签会话、分组管理的连接，以及内置的 SFTP 抽屉。Multi-tab sessions, grouped connections and an integrated SFTP drawer.

一个窗口，装下你打开的所有东西One window for everything you open

连接、终端、文件传输和端口转发并排放在同一个界面里，而不是散落在好几个工具中。Connections, terminals, file transfer and port forwarding sit next to each other instead of in separate tools.

三种认证方式Three ways to authenticate

密码、私钥与 SSH agent，需要时还可以把 agent 转发给远端主机。Password, private key or SSH agent — with optional agent forwarding for the remote host.

多标签会话Multi-tab sessions

每个会话一个标签，标签放不下时显示滚动指示，悬停即可展开。Every session gets its own tab, with scroll indicators when they overflow and hover-to-expand.

SFTP 抽屉SFTP drawer

面包屑路径导航，列出、上传、下载、重命名、新建目录与删除；复用已有的 SSH 连接，无需二次认证。Breadcrumb navigation, list, upload, download, rename, mkdir and delete — over the connection you already have, so no second sign-in.

端口转发与 SOCKS5Port forwarding & SOCKS5

本地转发、远程转发，以及自己实现的动态 SOCKS5 代理。Local forwarding, remote forwarding, and a dynamic SOCKS5 proxy implemented from scratch.

串口与 ZMODEMSerial ports & ZMODEM

波特率、数据位、校验位与流控都可配置，ZMODEM 传输直接跑在串口链路上。Baud rate, data bits, parity and flow control are configurable, and ZMODEM transfers run right over the serial link.

命令片段Command snippets

把每天都要敲的命令存成带标签的片段，一键发送到当前会话。Save the commands you type every day as labelled snippets and run them into the active session in one click.

快速搜索面板Quick search palette

一个模糊搜索框，同时找连接、串口、片段与转发规则。One fuzzy palette searches connections, serial ports, snippets and tunnels at once.

凭据加密保存Encrypted credentials

密码、私钥与口令通过操作系统密钥库加密保存，整个连接库一键导出为 JSON。Passwords, private keys and passphrases are encrypted with the operating system keystore, and the whole library exports to JSON in one click.

界面一览A look inside

深色与浅色主题，基于 xterm.js 的 WebGL 加速渲染。Dark and light themes, with xterm.js rendering accelerated by WebGL.

数据留在你本机Your data stays on your machine

连接、分组、片段、转发规则与设置全部存放在本机的 SQLite 数据库里；密码、私钥与口令经操作系统密钥库加密保存。除了你主动连接的主机之外，Termini 不与任何服务器通信。Connections, groups, snippets, tunnels and settings all live in a local SQLite database; passwords, private keys and passphrases are encrypted through the operating system keystore. Apart from the hosts you connect to yourself, Termini talks to nothing else.

没有遥测，没有统计分析，也没有云端账号。可选的 GitHub 登录完全由你主动发起，令牌不会离开这台设备。No telemetry, no analytics, no cloud account. The optional GitHub sign-in is user-initiated and the token never leaves the device.
