功能Features

一个窗口，装下你打开的所有东西One window for everything you open

连接、终端、文件传输和端口转发并排放在同一个界面里，而不是散落在好几个工具中。Connections, terminals, file transfer and port forwarding sit next to each other instead of in separate tools.

01

多会话标签，一屏之内Multi-tab sessions, one screen

每个连接、串口与本地 shell 都是一个标签页。标签放不下时自动出现滚动指示，悬停即可展开当前标签。Every connection, serial port and local shell gets its own tab, with scroll indicators and hover-to-expand.

  • xterm.js 5 + WebGL 加速渲染xterm.js 5 with WebGL-accelerated rendering
  • 终端内搜索：区分大小写、全词匹配、方向可选In-terminal search: case-sensitive, whole-word, either direction
  • 会话日志：滚动缓冲写入文件Session logging: rolling buffer written to a file
02

SFTP 就在手边SFTP within reach

不用另开工具。抽屉式面板带面包屑路径，列出、上传、下载、重命名、新建目录与删除都在同一块地方完成。No second tool needed. The drawer lists, uploads, downloads, renames, creates and deletes — all from the same panel.

  • 复用已有的 SSH 连接，无需二次认证Reuses the SSH connection you already have — no second sign-in
  • 多文件上传 / 下载，支持从桌面直接拖入Multi-file upload and download, plus drag-and-drop from the desktop
  • 路径面包屑随时回退到上层目录Breadcrumbs take you back up the tree at any time
03

串口连接与日志跟踪Serial ports and log tracking

波特率、数据位、校验位与流控可配置，ZMODEM 传输直接跑在串口链路上，串口日志同步落盘。Baud rate, data bits, parity and flow control are configurable, ZMODEM runs over the serial link, and the session log is written to disk.

  • 自动识别串口设备与常用波特率Serial devices and common baud rates detected automatically
  • ZMODEM 上传下载，无需额外工具ZMODEM upload and download without another tool
  • 日志实时写入文件，便于事后排查Logs stream to a file for later inspection

一个入口，四种连接One menu, four kinds of connection

SSH、串口、本地终端、端口转发与命令片段，都从右上角的同一个入口新建。SSH, serial ports, local shells, port forwards and command snippets — all created from the same menu.

模糊检索，一键直达Fuzzy search, one keystroke away

一个搜索框同时找连接、串口、片段与转发规则，输入几个字母就能跳过去。One palette searches connections, serial ports, snippets and tunnels — a few letters is all it takes.

配置丰富，中英文支持Rich settings, Chinese and English

主题、字体、字号、光标、滚动缓冲与窗口透明度都能调，界面语言随时切换。Theme, font, size, cursor, scrollback and window opacity — with the interface language switchable at any time.

主题Themes

浅色之外，还有深色Light, dark, and dark-plus

三套主题随你切换，切换即时生效，不需要重启。终端配色、背景色与界面一起变，字体、字号与光标样式也能单独指定。Three themes, switched instantly without a restart — the terminal palette and the whole interface follow along, and font, size and cursor style are yours to pick.

隐私Privacy

数据留在你本机Your data stays on your machine

连接、分组、片段、转发规则与设置全部存放在本机的 SQLite 数据库里；密码、私钥与口令经操作系统密钥库加密保存。除了你主动连接的主机之外，Termini 不与任何服务器通信。Connections, groups, snippets, tunnels and settings all live in a local SQLite database; passwords, private keys and passphrases are encrypted through the operating system keystore. Apart from the hosts you connect to yourself, Termini talks to nothing else.

可选的 GitHub 登录完全由你主动发起，令牌不会离开这台设备。The optional GitHub sign-in is user-initiated and the token never leaves the device.
